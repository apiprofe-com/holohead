HoloHead

A live face on a foam head. The phone sends the face; the iMac projects it.

1. Room code

The phone and the iMac must use the same code. Keep it private: anyone with it can call the head.

2. Open the pages

📱 Phone (Lucas): sender 🎭 Projector screen: projection 🎛 iMac screen: console 🖥 iMac screen: viewer (Lucas, for people at the iMac)

On the iPhone, open the phone link in Safari, then Share → Add to Home Screen.

3. Relay (automatic)

A shared Cloudflare relay is built in for registered room codes, so calls connect even when cellular or campus networks block a direct connection. Only fill this in to use a different relay. It's saved in this browser only.
